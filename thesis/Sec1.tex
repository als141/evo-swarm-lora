\chapter{序論}
\label{cha:1}

\section{研究背景}
\label{sec:1.1}

\subsection{小型言語モデルの集団による推論}
\label{sec:1.1.1}

大規模言語モデル（LLM）の性能は，パラメータ数，学習データ，計算量の拡大とともに向上してきた．しかし規模の拡大は学習と推論の費用を急速に押し上げるため，一つのモデルを大きくし続ける方法には経済的な限界がある．そこで，複数のモデル（または同じモデルの複数のインスタンス）を相互作用させ，集団として単体を超える性能を引き出す方向が注目されている．複数の回答を生成して多数決をとるだけでも，エージェントの数に応じて精度が伸びる\cite{li2024more}．複数のLLMが互いの回答を読んで自分の回答を更新するマルチエージェント議論（Multi-Agent Debate; MAD）\cite{du2023improving,liang2023encouraging}は，その代表的な方法である．

集団による推論は，小型のモデルにとって特に意味が大きい．約40億パラメータ（以下，4B級）のモデルは，単体では最先端の大規模モデルに及ばないが，1枚のGPUで多数のインスタンスを同時に動かせる．さらにLoRA\cite{hu2021lora}を用いれば，一つのベースモデルの上に軽量なアダプタを載せ替えるだけで，性格や役割の異なるエージェントを多数作れる．本研究は，Qwen3-4B-Instruct-2507\cite{qwen2025qwen3}を共有のベースモデルとし，役割ごとのLoRAを持つエージェントの集団を対象とする．

本研究の着想は人間の社会にある．人間の集団では，異なる視点や性格を持つ人が議論を通じて誤りを正し合う．個人は自分の経験から学ぶだけでなく，他者の成功を観察してそれを取り入れる（社会学習）．集団は，そのように蓄積した知識を世代を越えて受け渡し，時間とともに高度になる（文化的進化\cite{boyd1985culture}）．本研究は，この「対話→学習→世代交代」の循環をLLMのエージェントの社会で実装し，それによって社会の問題解決の精度が上がるかを検証する．

\subsection{マルチエージェント議論への批判}
\label{sec:1.1.2}

MADの効果には強い留保が付いている．計算量を揃えた比較では，MADは複数の推論経路の多数決をとるSelf-Consistency（SC）\cite{wang2023selfconsistency}に安定して勝てない\cite{smit2024should,zhang2025debate}．議論による信念の更新は期待値の上で正答率を改善せず，利得の大半は最後の多数決で説明できるという分析もある\cite{choi2025debate}．小型のモデルでは状況はさらに厳しく，1.5B〜7Bのモデルと数学の課題による比較では，同じトークン数の反復サンプリングより確実に良い手法は一つもなかった\cite{mirzaei2026samplemore}．同じモデルの複製同士の議論では，他者への同調が支配的になり，チームの誰かが正解していても最終回答が誤ることが多い\cite{cost2026consensus}．

これらの批判から，本研究は二つの要請を引き出す．第一に，集団による精度の向上を主張するには，生成回数と出力トークン数を考慮したSCと比べなければならない．第二に，エージェントを学習させる手法の効果を主張するには，同じデータで単一のモデルを自己学習させた場合と比べなければならない．エージェントが学習して強くなったのか，単に同じ問題で学習したから強くなったのかを区別するためである．

\subsection{ペルソナの設計の恣意性}
\label{sec:1.1.3}

MADでは，エージェントに「批判的な検証者」「創造的な発想家」のような異なるペルソナ（人物設定）を与えることが多い．しかし，性格を表すラベルだけのペルソナは，客観的な正解のある課題の精度をほとんど変えない\cite{zheng2024persona,kim2024persona}．一方，エージェントごとに異なる推論の手続きを割り当てると，同じ手続きのエージェント同士の議論より精度が上がるという報告がある\cite{liu2025dmad}．どのペルソナを何体組み合わせるかは，チームの成績を左右しうる設計変数であるにもかかわらず，多くの研究では直観で決められている．著者の予備研究（\ref{sec:1.2}節）も，3体のペルソナを直観で決めていた．

\section{予備研究と本研究の出発点}
\label{sec:1.2}

著者は2026年7月に予備研究を行った．予備研究では，性格を表す日本語のペルソナ文を持つ3体のLoRA（批判的検証者，実務的意思決定者，発散的探索者）を対話データで学習させ，議論のチームを作った．さらに，チームへの貢献（厳密Shapley値）を適応度として，LoRAの重みを交叉と突然変異で進化させた．その結果，チームは1問あたり6回の生成を使いながら，9回の生成のSC@9にも，同じ6回の生成のSC@6にも有意に及ばず，進化による改善も確認できなかった．

本研究の準備として，予備研究のコードと保存済みのすべての生出力を再検証した（第\ref{cha:5}章）．その結果，予備研究は「チームへの貢献による進化」を検証できる状態になかったことが分かった．理由は次の4点である．
\begin{enumerate}
\item \textbf{ペルソナの学習が能力を損ない，多様性を生まなかった}: 短い応答からなる対話データでの学習が推論の記述を約半分に縮め，長い導出を要する数学の問題の精度を下げていた．また，異なるペルソナ間の回答の不一致率は，同じエージェントを乱数だけ変えて再サンプリングした場合と区別できなかった．
\item \textbf{議論が同調に支配されていた}: 議論の実装がエージェントに自分の前回の回答を提示していなかった．そのため，round0で少数派だったエージェントは，自分が正解でも81〜95\%の確率で誤った多数派に答えを変えていた（エージェント単位の割合）．
\item \textbf{進化が選抜として機能していなかった}: 初期の集団には遺伝的な多様性がなく，交叉と突然変異は重みをほとんど動かしていなかった（進化の前後で$\Delta W$のコサイン類似度0.9996以上）．さらに，100問で測る適応度の誤差が候補間の差を上回っており，選抜はノイズの判定になっていた．
\item \textbf{採点器に条件によって偏った欠陥があった}: 回答の抽出の誤りにより，MMLU-Proでベースモデルの回答の約1割を誤って「A」と読んでいた．また，数学の回答の同値判定が不十分で，予測の約6.5\%で正しい回答を誤答と判定していた．前者の誤りはベースモデル系の条件にだけ強く現れ，条件間の比較を歪めていた．
\end{enumerate}

これらの問題は，それぞれ本研究の設計原理になった．ペルソナは性格のラベルではなく推論の手続きとして定義し，チームとしての成績で選ぶ．議論では自分の前回の回答を提示する．進化では，個体が議論の中で正解に至った発話から学ぶことで，候補間に意味のある差を作る．選抜には十分な数の問題を用い，最終評価の問題とは分ける．採点器は監査して評価の前に固定し，統計の計画は結果を見る前に固定する．

\section{研究課題}
\label{sec:1.3}

本研究は次の4つの研究課題に答える．

\begin{description}
\item[RQ1（進化の効果）] 進化的社会学習を世代を重ねて行うと，社会（3体のペルソナの議論チーム）の未見問題での精度は，世代0の社会より上がるか．
\item[RQ2（選抜の効果）] チームへの貢献（厳密Shapley値）による選抜は，選抜を行わない社会学習より高い精度をもたらすか．
\item[RQ3（適応度の水準）] チームへの貢献による選抜は，個体の単独の精度による選抜より優れるか．
\item[RQ4（位置づけ）] 最終世代の社会は，ベースモデル単体，生成回数を考慮したSC，同じ問題で単一のモデルを自己学習させた場合と比べて，精度と計算量の上でどこに位置するか．
\end{description}

RQ1〜RQ3に対応する3つの主要な比較（H1〜H3）と検定の方法，問題集合，中止規則は，本実験の結果を見る前に固定した（第\ref{cha:4}章）．

\section{提案手法の概要}
\label{sec:1.4}

本研究は，性格の異なるペルソナを持つLoRAエージェントの社会が，議論を通じて問題を解き，その議論から学び，チームへの貢献で次世代の代表を選ぶ\textbf{進化的社会学習}を提案する（第\ref{cha:3}章）．手法は次の3つの要素からなる．

\begin{itemize}
\item \textbf{世代0のペルソナの選定}: 人間の問題解決チームの役割を分類したBelbinのチーム役割\cite{belbin1981management,belbin1993team}の9役割を網羅的に候補とし，それぞれを推論の手続きとして操作化する．単独の評価，釣り合い型の実験計画によるチームの評価，別の問題での確認という3段階で，チームとしての成績に基づいて3体を選ぶ．既定の3体を置き換えるかどうかは，事前に定めた決定規則で決める．
\item \textbf{議論}: 各エージェントが独立に解き（round0），自分の回答を保持したまま他者の回答を読んで解き直す（round1）．全員の答えが一致した問題では議論を省き，議論した問題では多数決で最終回答を決める．
\item \textbf{進化的社会学習}: 各世代で，社会が新しい学習用の問題を議論する．各ペルソナのLoRAは，自分が正解した発話から学ぶ子（自己学習）と，自分が誤り他者が正解した問題で他者の解き方を学ぶ子（社会学習）を作り，両者を重みの空間で平均した子も加える．親と3体の子のうち，親の社会の中で全7連合の精度を実測して求めた厳密Shapley値が最大のものを，次世代の代表とする．
\end{itemize}

個体が議論で得た経験を学習して重みに取り込み，それが子に引き継がれる点はラマルク的な継承\cite{whitley1994lamarckian}に，集団がチームへの貢献で代表を選ぶ点はダーウィン的な選抜に当たる．学習と選抜の二重の継承を持つ点で，本手法は文化的進化\cite{boyd1985culture}の構図に対応する．

検証では，選抜を行わない系統，単独の精度で選ぶ系統，ペルソナと議論を用いない単一モデルの自己学習（RFT）\cite{zelikman2022star,yuan2023scaling}，SC@$k$を対照に置く（第\ref{cha:4}章）．

\section{本研究の貢献}
\label{sec:1.5}

本研究の貢献は次のとおりである．

\begin{enumerate}
\item \textbf{少ない生成回数でSC@9と同等の精度に達する議論の社会}: 自分の前回の回答を会話履歴に保持する議論のプロトコルと，全員一致の問題で議論を省くゲーティングを組み合わせた4B級のモデルの3体の議論の社会が，ベースモデル単体とSC@3を有意に上回り，1問あたり約4回の生成で9回の生成のSC@9と$\pm 2$ptの範囲で同等の精度に達することを示した．生成回数と出力トークン数を揃えたSC@4も$+1.44$pt上回り，この差はSC@$k$の定義と計算量の揃え方を変えても0.9〜1.4pt残った（SC@4との比較は事前登録の副次的な比較で，多重性を補正すると有意でない．定義を変えた比較は探索的である）．この上積みの大部分は議論によるが，同程度以上の議論の上積み（約2.3pt）は予備研究の手続きでも見られ，本研究のプロトコルに固有のものとはいえなかった．
\item \textbf{進化的社会学習の定式化と，その限界の実証}: 議論の正解発話からの学習（ラマルク的継承）と，全連合を実測した厳密Shapley値による選抜（ダーウィン的選抜）を組み合わせた世代の手続きを定式化した．事前に固定した計画のもとで，3世代の進化では社会の精度が上がらず（$-0.27$pt，$p = 0.43$，$\pm 2$ptの範囲で同等），選抜の有無の差も，チームへの貢献と単独の精度という選抜の基準の違いも検出されないことを示した．その理由を，学習の信号の小ささ，選抜の推定誤差，親の値の上振れという観点から，定量的な根拠とともに考察した．
\item \textbf{理論に基づくペルソナの選定の手続き}: チーム役割理論から網羅的に作った候補を推論の手続きとして操作化し，釣り合い型不完備ブロック計画と事前に定めた決定規則によって，チームとしての成績からペルソナを選ぶ手続きを示した．ペルソナの選び方を，直観ではなくデータと事前の規則で説明できるようにした．同時に，推論の手続きとしてのペルソナの違いが議論のチームの精度を左右するという証拠は得られなかった．
\item \textbf{予備研究の再検証と評価の方法論}: 予備研究の生出力を監査し，採点器の欠陥が条件によって偏って効き，条件間の比較を歪めていたことを定量的に示した．選抜と最終評価の問題の分離，監査して固定した採点器，固定した実行環境，事前に固定した統計の計画という評価の手続きを示した．
\end{enumerate}

\section{本論文の構成}
\label{sec:1.6}

第\ref{cha:2}章では，マルチエージェント議論と集約，ペルソナと役割，議論からの学習，進化的なモデル最適化，チームへの貢献の定量化，評価の信頼性に関する研究を整理し，本研究の位置づけを述べる．第\ref{cha:3}章では，世代0のペルソナの選定，議論のプロトコル，チームへの貢献，進化的社会学習の手続きを定式化する．第\ref{cha:4}章では，問題集合，採点，比較する系統，統計の計画，パイロットで決めた設計値を述べる．第\ref{cha:5}章では，予備研究の再検証と本実験の結果を報告する．第\ref{cha:6}章では結果を考察し，本研究の限界を述べる．第\ref{cha:7}章で結論と今後の課題を述べる．
