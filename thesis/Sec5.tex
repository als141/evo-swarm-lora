\chapter{考察}
\label{cha:5}

\section{実験結果の解釈: 議論の効果は2軸のトレードオフで決まる}
\label{sec:5.1}

実験1の最も重要な発見は，マルチエージェント議論の効果が単一の符号を持たず，ベンチマークによって系統的に反転することである．素の議論はMATH-500で$+4.2$pt・SuperGPQAで$+3.1$ptと有意に有効だが，MMLU-Proでは$-4.1$ptと有意に有害だった（いずれも問題IDクラスタ解析; \S\ref{sec:4.4}）．逆にLoRAペルソナチームはMMLU-Proでのみ有効だった．この対照は，議論チームの性能を（i）\textbf{多様性の利得}（異なる推論経路が正解を発見する確率の向上）と（ii）\textbf{個体能力の毀損}（ペルソナ注入が支払うコスト）という2軸のトレードオフとして整理すると一貫して説明できる．

MMLU-Proのような知識推論では，温度サンプリングだけでは推論経路の多様性が乏しく（実験1で素の議論はベース単体より悪化），重みに焼き込まれたペルソナが供給する視点の多様性が利得をもたらす．一方でペルソナSFTの能力毀損は比較的軽微であり，差し引きで正となる．MATH-500やSuperGPQAのような長い導出を要する領域では，多様性は温度サンプリングでも十分に確保できる（素の議論やSC@9が強い）一方，SFTによる能力毀損が致命的となり，差し引きが負に転じる．

この整理は先行研究間の見かけ上の矛盾（「議論は多数決に劣る」とする報告と「議論が小型モデルで有効」とする報告の併存）を説明しうる．特にMATH-500における素の議論の有意な効果は，「議論単体は信念のマルチンゲールを誘導し期待正解率を改善しない」という近年の定理的整理\cite{choi2025debate}が\textbf{少なくともMATH-500というベンチマークでは成り立たない}ことを示す反例である．この反転の機構として本論文は「検証可能な問題では他者の解の正誤を自己検算でき，信念更新が訂正方向へ偏る」という\textbf{検証可能性仮説}を提示し，MATH-500の集約損失がほぼゼロである観察（表\ref{tab:4.oracle}）はこれと整合する．ただし\S\ref{sec:4.6.6}のカテゴリ別分析が示すとおり，この仮説はMMLU-Pro内部の定量系カテゴリでは\textbf{再現しなかった}（mathカテゴリではむしろ$-9.3$ptの悪化）．したがって本研究のデータから直接支持されるのは「効果がベンチマーク単位で反転する」ことまでであり，反転を規定する要因が問題内容の検証可能性なのか，出題形式（選択肢の有無）・難易度分布・出力長などベンチマーク構成の複合なのかの分離は今後の課題である．

\section{損失分解が導いた処方とその効果}
\label{sec:5.2}

実験1の診断（\S\ref{sec:4.6.2}）はチームの誤差を個体能力損失と集約損失に分解し，それぞれに対応する処方を実験2で検証した．

\textbf{能力毀損の機構と修復}．ペルソナSFTがベースモデルの思考連鎖を半分以下（中央値2{,}423字$\rightarrow$1{,}188字）に圧縮していたという生成ログの観察は，毀損の主因が「短い応答スタイルの刷り込みによる長い導出能力の選択的破壊」であることを示す．これはSFTデータとモデル分布のギャップが忘却を生むという近年の知見と整合する．処方としてベースモデル自身が生成した検証済みの長い思考連鎖（平均6{,}503字）を約38\%混合して再学習したところ，solo精度は3ベンチマークすべてで基準を満たし，一部はベース単体を上回った（G1）．再学習チームは旧チームを同一測定環境でMMLU-Pro $+3.7$pt・MATH-500 $+6.1$pt上回った．ただし本研究はペルソナ間の行動多様性の直接測定（回答不一致率の推移など）を最終評価では実施していないため，「多様性を保ったまま能力を回復した」とまでは主張できない——ここで言えるのはチームとしての性能が回復したことである．なお再学習は，リプレイデータの追加と同時にrank（$32 \to 16$）・学習率・エポック数・系列長（$1{,}024 \to 8{,}192$）も変更しており，回復のどこまでがリプレイ自体の寄与かは分離できていない（交絡; \S\ref{sec:5.5}）．

\textbf{集約損失と検証型集約}．SuperGPQAでは3体のうち少なくとも1体が正解している問題が51.7\%あるにもかかわらず，多数決＋議論は38.7\%しか回収していなかった．logprobに基づく重み付き投票は$+0.7$ptの改善に留まり，比較選択型の裁定（GenSelect型）は上積みを示さなかった（G2）．集約損失の大部分は依然として未回収であり，「正解が少数派である問題」の回収は4B級では未解決の課題として残る．なお実験2でsolo能力が修復された結果，議論後に票が割れる問題自体が減少したため，集約改善の寄与余地が実験1の見積もりより縮小した点には注意が必要である．

\textbf{条件付き更新と匿名化}．「自己の推論に具体的な誤りを特定できた場合のみ回答変更を許す」条件付き更新はパイロットで$+1.0$pt（非有意）と小さいが悪化のない効果を示し，発言の匿名化と併せて採用した．これらは追従（sycophancy）による正解の破壊——実験1では500問中26問で正しい多数派が議論後に崩壊していた——への対処であり，議論の信念更新を訂正方向へ偏らせる介入として位置づけられる．

\section{進化的最適化の再解釈: 選抜ではなく修復}
\label{sec:5.3}

本研究の当初の中心仮説は「チームレベル適応度（厳密Shapley値）による選択圧が協調的な個体を選抜する」であった．実験1の結果はこの仮説を支持しない．進化の寄与はMATH-500の$+4.3$pt（有意）のみで，選抜対象としたMMLU-Proではゼロだった．さらに機構分析（\S\ref{sec:4.6.2}）は当初の想定より根本的な問題を明らかにした．進化前後のLoRAの$\Delta W$はFrobeniusノルム比1.000に加え\textbf{cosine類似度0.9997--1.0000でほぼ同一}であり，突然変異1回あたりcos $=0.9997$，交叉1回あたりcos $=0.9998$しか重みを動かしていなかった．すなわち本実験の進化は\textbf{重み空間の探索としてほとんど機能しておらず}，6世代を通じて初期個体の極近傍に閉じていた．初稿では「ノルム保存の下での方向回転が損傷成分を打ち消した（修復機構）」と解釈したが，cosine解析によりこの解釈は\textbf{棄却}される——方向は回転していなかった．MATH-500の$+4.3$ptは，固定された極小の重み摂動に対する生成過程の敏感な応答（評価環境の違いだけで$+6$pt級の系統差が生じるという\S\ref{sec:4.6.4}の観察と同種の感度）として説明するのが最も保守的であり，重み空間における意味のある「修復」があったとは言えない．

この帰結を選抜ノイズ・sharing無効の検証と合わせると，本実験の進化ループは三重の機能不全を抱えていたことになる．（i）\textbf{探索の不全}: 進化演算子の実効摂動が極小で，候補間に意味のある差が生成されていなかった．（ii）\textbf{多様性圧の不全}: fitness sharingは$K=2$構成で選抜中立だった（\S\ref{sec:4.6.6}）．（iii）\textbf{選抜の不全}: 適応度100問の標準誤差$\pm 4.9$ptの下での毎世代最大値選抜は1〜2pt差の真の優劣を判別できず（必要問題数の試算は1判断あたり約2{,}600問），開発セット上の見かけの改善（$+12$pt）は勝者の呪いとして説明される．重要なのは，これらがいずれも\textbf{実装・設計パラメータの不備であって，チームレベル適応度という枠組み自体の反証ではない}ことである．本研究が実証的に示せたのは「本実装は枠組みの有効性を検証できる状態になかった」までであり，枠組みの検証には変異幅の拡大・$K \geq 3$のサブ集団・識別力の高い適応度セット（IRT型の問題厳選や逐次半減法）を備えた再実験，およびsolo適応度・ランダム選抜との対照（アブレーションA1）が必要である．一方，能力回復という目的に対しては実験2のリプレイ再学習が確実に機能した（再学習チームは進化後チームをクラスタ解析で$+2.7$pt上回る）ため，本研究では処方の検証を優先した．

\section{Self-Consistencyとの比較の最終形}
\label{sec:5.4}

生成回数を揃えたSelf-Consistency（SC@9）は本研究を通じて最強のベースラインであり続け，測定環境を統一した最終評価では，診断に基づく処方を尽くした再学習チームですら$-3.5$pt $[-4.5, -2.6]$（問題IDクラスタ解析，$p<10^{-4}$）と有意に及ばなかった．「評価設計を厳密にするとMADの優位は消える」という批判\cite{smit2024should}を，（i）生成回数を揃えた比較（トークン実測ではSC@9の方が総トークンで多く，チーム側が計算量で優遇された比較ではない; \S\ref{sec:4.6.6}），（ii）問題IDクラスタリングを考慮した対応あり検定と多重比較補正，（iii）能力毀損の回復と集約改善という対策の実施，（iv）測定環境の統制，のすべてを満たした上で確認した結果であり，本研究で最も統制の効いた知見である．

敗因の構造は明快である．SC@9の強さは「同一分布からの独立な9サンプルの多数決」がもたらす分散削減にあり，ベース単体（1サンプル）に対して$+2.8$pt（$p<10^{-4}$）を安定して稼ぐ．一方チーム議論は6生成をペルソナ3体$\times$2ラウンドに配分するため，独立サンプル数では3にすぎず，議論による情報交換がその差を埋める必要がある．実験2の集約改善後もこのギャップは埋まらなかった．例外はMATH-500であり，チームとSC@9の差は検出されず（$-0.8$pt，$p=0.35$．ただし90\%信頼区間$[-2.13, +0.45]$の下限が等価マージン$-2$ptをわずかに超えるため同等性は未確定），ベース単体には$+3.4$pt（$p=0.010$）と有意に優る．MATH-500では議論の1ラウンドが誤答の訂正として機能し，少ないサンプル数をほぼ補償したことを示す．

なお実験2の途中経過（測定環境の統制前）では「チームがSC@9をMMLU-Proで$+5.5$pt上回る」という結果が一時得られたが，これは評価イメージ間の系統差（\S\ref{sec:4.6.4}）の産物であった．系統差はベースモデルの素の生成に選択的に現れLoRA適用時にはほぼ現れないため，\textbf{ベース系条件だけが過小評価され，チーム側が見かけ上優位になる}という質の悪いバイアスを生む．マルチエージェント議論の評価においてベースライン測定の環境同一性がいかに重要かを示す実例である．

\section{本研究の限界}
\label{sec:5.5}

\begin{itemize}
\item \textbf{規模の限界}: 3エージェント・単一モデル系列（Qwen3-4B）・3ベンチマークでの結果であり，より大きなモデルや異種モデル混成チームへの一般化は未検証である．特に「能力毀損」はベースモデルの事後学習の質に依存するため，モデル系列が変われば定量関係は変わりうる．
\item \textbf{実験1と実験2の数値の非互換}: 評価イメージ間の系統差（\S\ref{sec:4.6.4}）により，実験1（旧環境）と実験2（新環境）の絶対値は直接比較できない．実験1の内部比較（領域依存性・損失分解）と実験2の内部比較（処方の効果・対SC@9）はそれぞれ同一環境内の対応あり比較として有効だが，例えば「実験1の素の議論と実験2の再学習チーム」のような環境跨ぎの比較は本論文では行っていない．
\item \textbf{シード数の非対称}: 最終評価はSC@9と再学習チームが6シード，ベース単体と旧チームが3シードであり，後者を含む検定は検出力がやや低い．
\item \textbf{進化ループの機能不全}: 実験1の進化は，（i）進化演算子の実効摂動が極小（$\Delta W$のcosine類似度0.9997以上），（ii）fitness sharingが$K=2$で選抜中立，（iii）適応度測定の標準誤差$\pm 4.9$ptに対し候補間差が小さい，という三重の機能不全を抱えていた（\S\ref{sec:5.3}）．したがって本研究は「チームレベル適応度による進化」の有効性を支持も反証もできていない．変異幅の拡大・$K \geq 3$・識別力厳選と逐次半減法を備えた再実験（設計は研究設計書v3 \S 3.4として保存），およびsolo適応度・ランダム選抜との対照（A1）が必要である．
\item \textbf{進化ループの生成条件}: 進化ループは最大512トークン・top-p 0.9の旧生成設定で実行されており，最終評価（8{,}192トークン・top-p 0.8）と生成条件が異なる．ループ内部の比較は全個体で条件が揃っているため公正だが，進化時と評価時の挙動差は残る．
\item \textbf{未実施のアブレーション}: solo適応度進化（A1）等は計算資源の制約から未実施であり，チームレベル適応度の寄与の直接分離は今後の課題である．A2（sharing無効化）は$K=2$構成では自明に無差となるため，そもそも本構成では検証不能であった．
\item \textbf{リプレイ再学習の交絡}: 実験2の再学習はリプレイデータの追加と同時にrank・学習率・エポック数・系列長も変更しており，能力回復のどこまでがリプレイ自体の寄与かは分離できない．「思考連鎖の圧縮が能力毀損の原因」という機構の説明も，圧縮と精度低下の相関および圧縮解消と精度回復の同時観察に基づく仮説であり，因果の単離実験（リプレイのみを変えた対照）は行っていない．
\item \textbf{検証可能性仮説の適用限界}: 議論効果の反転を「問題の検証可能性」で説明する解釈は，ベンチマーク間の観察とは整合するがMMLU-Pro内部のカテゴリ別分析では再現しなかった（\S\ref{sec:4.6.6}）．本研究のデータが直接支持するのは「ベンチマーク依存の反転」までである．
\item \textbf{評価領域}: 全ベンチマークが英語の選択式・短答式であり，生成型タスクや日本語タスクへの外的妥当性は限定的である．
\end{itemize}
