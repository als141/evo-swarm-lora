\label{cha:5}

\section{予備研究の再検証}
\label{sec:5.1}

\subsection{予備研究の構成}
\label{sec:5.1.1}

予備研究（2026年7月）では，日本語のペルソナ文を持つ3体（批判的検証者，実務的意思決定者，発散的探索者）のLoRAを，それぞれ60件の対話データで学習させた（以下，旧チーム）．議論では，各エージェントが独立に回答した後，他の2体の回答を読んで回答を更新し，多数決で最終回答を決めた．この旧チームを初期集団として，代表チーム文脈の厳密Shapley値にfitness sharingを掛けた適応度で，LoRAの重みを交叉と突然変異により6世代進化させた．適応度はMMLU-Proの100問で測った．その後，能力の低下を補うため，ベースモデル自身の正解の長い推論を混ぜた対話データで3体を学習し直し，議論の手続きに条件付きの更新，発言の匿名化，確信度で重み付けした投票を加えたチームを作った（以下，7月のチーム）．評価はMMLU-Pro 500問，MATH-500のLevel 4--5の200問，SuperGPQA 300問を3〜6本の生成seedで行った．

\subsection{予備研究が失敗した理由}
\label{sec:5.1.3}

保存済みの生出力と進化の記録を解析し，予備研究のチームと進化が機能しなかった理由を特定した．

\textbf{ペルソナの学習による能力の低下}．学習に用いた対話データの応答は平均779文字と短く，学習後のエージェントは推論の記述を約半分（ベースモデルの平均2,423文字に対し1,188文字）に縮めた．その結果，長い導出を要するMATHのLevel 5の問題で精度が大きく下がった．進化後の旧チームは，ベースモデル単体に$-2.62$pt（$[-4.31, -0.91]$）及ばなかった．

\textbf{多様性の欠如}．同じ問題集合で，異なるペルソナのエージェント同士の回答の不一致率と，同じエージェントを乱数だけ変えて再サンプリングしたときの不一致率を比べると，差は$-0.9$〜$+1.4$ポイントにすぎなかった．3体のうち少なくとも1体が正解する割合（oracle@3）も，ベースモデルの3本の標本のoracle@3を上回らなかった．ペルソナの学習は，再サンプリング以上の多様性を生んでいなかった．

\textbf{同調}．予備研究の議論は，更新のラウンドでエージェントに自分の前回の回答を提示していなかった．このためround0で少数派だったエージェントは，自分が正解であっても81〜95\%の確率で多数派の誤答に答えを変えた．少数派の正解が議論で生き残る経路がほぼなかった．

\textbf{選抜のノイズ}．進化の記録では，同じ連合を同じ条件で測り直した値が単独で標準偏差3.2pt揺れた．この揺れを伝播させると，候補間のShapley値の差のノイズの標準偏差は約1.9ptになる．一方，実際に観測された候補間の差の中央値は1.2ptであり，18回の選抜はすべてノイズの2標準偏差以内の差で決まっていた．観測された差の分散は純粋なノイズの期待値を下回っており，候補間に真の差の分散は検出されなかった．選抜時の最大値は次の世代の再測定で平均3.2pt下がり，開発用の問題での「+12pt」の改善は，毎世代の最大値を拾う勝者の呪いとして説明できた．加えて，交叉と突然変異は重みをほとんど動かしておらず，進化の前後の$\Delta W$のコサイン類似度は全モジュールで0.9996以上だった．候補間に差がなく，差があっても測れない状態だったことになる．予備研究のデータを再標本化して試算すると，真の差が約3ptの2条件で正しい方を選ぶ確率は，無作為に選んだ100問では0.77〜0.78にとどまるが，正答率が中間の問題を70\%に濃縮した300問では0.96〜0.97になる．

\subsection{本研究への示唆}
\label{sec:5.1.4}

以上の再検証から，本研究の設計を次のように定めた（第\ref{cha:3}章，第\ref{cha:4}章）．
\begin{itemize}
\item ペルソナは性格のラベルではなく推論の手続きとして定義し，ペルソナ文だけで与える（学習による能力の低下を避ける）．候補は理論から網羅的に作り，チームとしての成績で選ぶ．
\item 議論では自分の前回の回答を会話履歴に保持する（同調の実装上の原因を除く）．
\item 候補間の差は，重みの乱数的な摂動ではなく，議論の正解発話からの学習で作る．
\item 選抜には400問のdevを用い，選抜の単位ごとに全7連合を実測する．最終評価のtestは選抜と分ける．
\item 採点器は監査して固定し，すべての結果を同じ採点器で採点する．
\end{itemize}

\label{sec:5.2.1}

\subsection{段階2: チームの精度と役割の主効果}
\label{sec:5.2.2}

14チームのdev-Aでのmacro精度を表\ref{tab:5.3}に，役割の主効果を図\ref{fig:5.1}に示す．チームの精度は74.2〜79.6\%に分布した．最も高かったのはShaper，Specialist，Teamworkerのチーム（79.6\%）で，ペルソナを持たないplain 3体のチームも同じ79.6\%だった．既定トリオは78.4\%だった．200問でのチームのmacro精度の標準誤差は約3ptであり，チーム間の差の多くはこの範囲に収まる．

式(\ref{eq:maineffect})の加法モデルで推定した役割の主効果は，Teamworkerの$+2.4$ptからCompleter Finisherの$-1.6$ptまでだった．Belbinの中心的な主張である「役割のそろったチームほど成績が高い」については，3群から1体ずつのバランス型9チームの平均精度が，同じ群の3体からなる同質型3チームより1.0pt低く，チームのラベルの並べ替え検定で$p = 0.49$だった．この仮説は本研究のデータでは支持されなかった．

探索的に，14チームの精度を構成員の単独精度の平均と，round0の2体間の回答の不一致率で説明できるかを調べた．チームの精度は構成員の単独精度の平均と弱い正の相関を示した（$r = 0.46$）が，不一致率とはほとんど相関しなかった（$r = -0.09$）．チーム数が14と少ないため，いずれも確かな関係とはいえない．一方，3体のうち少なくとも1体がround0で正解した問題の割合（oracle@3）は84〜89\%であり，チームの最終的な精度（74〜80\%）を約9pt上回った．チームの中に正解があっても，議論と多数決で最終回答にできなかった問題が相当数ある．

\section{議論と選抜の分析}
\label{sec:5.5}

\subsection{議論の上積みと同調}
\label{sec:5.5.1}

議論（round1）の効果を，構成員のround0の回答の多数決（議論なし）と比べて測った．世代0の社会では，議論ありが議論なしを$+0.98$pt（$[+0.32, +1.64]$，$p = 0.004$）上回り，系統Sの最終世代でも$+1.14$pt（$p = 0.006$）上回った．本研究の議論のプロトコルは，多数決だけの場合より精度を確かに上げた．

議論の正誤の遷移を図\ref{fig:5.5}に示す．round0で1体だけが正解していた問題で，その正解が議論の後も保たれた割合は，世代0の社会で34\%だった．予備研究の手続き（自分の前回の回答を提示しない）による7月のチームでは7\%であり，自分の回答を会話履歴に保持する本研究のプロトコルは，少数派の正解が議論で失われる割合を大きく減らした．ただし，全員が一致しなかった問題でのエージェントごとの遷移は，正解から誤答へ（32\%）と誤答から正解へ（33\%）がほぼ同じ割合で起きた．7月の手続きでは正解から誤答への遷移は8\%と少なかったが，これは回答が多数派に合わせて決まり，多数派にいる正解は動かない一方で少数派の正解がほぼ失われる同調の結果である．本研究のプロトコルでは回答が双方向に動きやすくなり，その差し引きとして，議論なしの多数決を約1pt上回った．

3体のうち少なくとも1体がround0で正解した割合（oracle@3）は，世代0の社会で77.1\%（macro）であり，最終的な精度（72.8\%）を4.3pt上回った．チームの中にある正解のうち，議論と多数決で最終回答にできなかったものがなお残っている．

\subsection{個体の精度と多様性}
\label{sec:5.5.2}

構成員のround0の単独の精度（macro）の平均は，世代0で69.7\%，系統Sの最終世代で69.5\%，系統Nの最終世代で69.5\%だった．社会学習を重ねても，個体の単独の精度は上がらなかった．同じ期間に，RFTは単独の精度を$+0.64$pt上げている．構成員の2体間の回答の不一致率は，世代0で0.19，系統Sの最終世代で0.19，系統Nの最終世代で0.18であり，同じプロンプトでベースモデルを再サンプリングしたときの不一致率（0.18）とほぼ同じだった．世代を重ねても，ペルソナ間の回答の多様性は増えなかった．

\subsection{Shapley値と単独の精度}
\label{sec:5.5.3}

系統Sの選抜の候補について，Shapley値と単独の精度の順位相関（Spearman）は0.80であり，両者はおおむね同じ順位を与えた．9回の選抜（3世代×3役割）のうち，Shapley値が最大の候補と単独の精度が最大の候補が食い違ったのは1回だった．食い違ったのは世代3のMonitor Evaluatorで，単独の精度が最大の子（75.2\%）ではなく，Shapley値が最大の親が据え置かれた．Banzhaf値で選んだ場合の結果は9回中8回でShapley値と一致した．一致しなかったのは世代1のPlantで，Shapley値の差が0.0003と極めて小さい選抜だった．
