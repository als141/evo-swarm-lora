（英: Evolutionary Social Learning of Persona-LoRA Societies with Team-Level Contribution in Multi-Agent Debate）

## 章立て

1. **序論**
   - 背景: 小型 LLM の集団推論、MAD への批判（SC に勝てない、同質性、追従）。
   - 人間社会の比喩: 性格の違う個体が対話で学び合い、世代を重ねる。
   - RQ1〜4 と貢献。
2. **関連研究**
   - MAD と集約（SC、GenSelect、RSA、DMAD）
   - ペルソナと役割（Belbin・Six Hats・Hong & Page、ペルソナ効果の限界）
   - 議論からの学習（Multiagent Finetuning、MACA、CANON、SDRL）
   - 進化的モデル最適化（GENOME、PopuLoRA、Model Swarms、Heterogeneous Swarms、AC/DC）
   - チーム貢献（Shapley・Banzhaf、差分評価、RL の credit 割当）
   - 評価の信頼性（採点器、非決定性、ノイズ下の選抜）
   - 位置づけ表を最新化する
3. **提案手法**
   - 3.1 世代0: Belbin 役割プールからのチーム選定（プロンプト空間）
   - 3.2 議論プロトコル（自己回答提示、集約の定義）
   - 3.3 チーム貢献度（厳密 Shapley と Banzhaf、代表チーム文脈）
   - 3.4 進化的社会学習: 自己学習 a / 社会学習 b / 兄弟交叉 c、選抜、ラマルク的継承
   - 3.5 計算量
4. **実験設定**
   - 問題集合: dev/test/train の分離と事前登録
   - 評価環境: digest 固定、採点器の監査、非決定性
   - 系統: S / N / A1 / RFT、ベースライン
   - 統計: macro、クラスタ置換、Holm、同等性
5. **実験結果**
   - 5.1 **予備研究（2026-07 の結果の圧縮版）**: 1.5〜2 ページと図1〜2枚
     - 性格ラベルのペルソナ SFT は能力を損ない、多様性を生まない（CoT 圧縮、再サンプリングと同等の不一致率）
     - 議論は同調に支配されていた（自己回答の非提示）
     - 重み GA の進化は多様性ゼロの集団をノイズで選抜していた
     - 採点器の欠陥の発見と訂正（MMLU-Pro 偽 'A'、MATH 偽陰性 6.5%）。これが v4 の設計原理になる
   - 5.2 **世代0の選定**: 役割の主効果、バランス仮説、既定トリオとの比較、採用チームの Shapley
   - 5.3 **進化的社会学習**: 世代推移、S / N / A1 の比較（RQ1〜3）、選抜の中身（どの子がなぜ選ばれたか、Shapley と単独の食い違い）
   - 5.4 **位置づけ**: ベース・SC@k・RFT・7月チームとの比較、精度–計算量曲線（RQ4）
   - 5.5 **分析**: 議論の正誤遷移（同調率の変化）、多様性の推移、ベンチ別の効果
6. **考察**: 人間社会との対応（社会学習・文化的進化）、何が効いたか、SC との関係、限界
7. **結論**
