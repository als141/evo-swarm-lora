# 研究設計書: チームレベル適応度によるペルソナLoRA集団の進化的最適化

作成: 2026-07-03（文献調査 4 本の結果に基づく。出典は本文中の arXiv ID を参照）

---

## 1. 研究課題 (RQ)

**RQ1 (主)**: マルチエージェント議論（MAD）のチームレベル適応度 — 厳密 Shapley 値による
協調寄与 — を選択圧としてペルソナ LoRA 集団を進化させると、
(a) 個体タスク性能のみを適応度とする進化（GENOME 型）、
(b) 非進化ベースライン（Self-Consistency・素の debate）
を上回るチームが得られるか。

**RQ2 (副)**: 4B 級の小型モデルにおいて、重み空間に焼き込まれたペルソナ多様性は、
プロンプト+温度サンプリングによる多様性よりも debate の性能改善に寄与するか。

**RQ3 (探索的)**: 進化の過程でチームの行動多様性（回答不一致プロファイル）は
どう変化し、チーム性能とどう相関するか（Krogh & Vedelsby の ambiguity 分解の観点）。

## 2. 新規性の主張と関連研究マップ

文献調査（2026-07-03 実施）の結論: **「議論のチームレベル適応度 × LoRA 重み集団の
世代交代型進化」の交点は未報告**。ただし包囲網は狭く、以下の対比が必須:

| 系統 | 代表 | 欠けている要素 |
|---|---|---|
| LoRA集団+進化演算 | GENOME (2503.01155), EvoPref (2605.09777) | 適応度が個体性能のみ |
| LoRA集団+相互作用共進化 | PopuLoRA (2605.16727) | 敵対的self-play、協調でない |
| 議論品質を最適化信号に | MAPoRL (2502.18439) | RLであり集団進化でない |
| チーム適応度でMAS進化 | EvoMAS (2602.06511), Meta-Team (2605.29790) | 進化対象がプロンプト/構成 |
| LoRA重み空間の協調探索 | Model Swarms (2410.11163, ICML25) | PSO・個体効用・世代交代なし |
| debate由来データでSFT | Multiagent Finetuning (2501.05707, ICLR25) | 勾配模倣であり選択圧でない |

**貢献文（案）**:
1. 議論チームへの限界貢献を **3エージェント構成で厳密に計算可能な Shapley 値**
   として定式化し、LoRA 集団進化の適応度に組み込む初の研究
2. 協調的共進化 (Potter & De Jong 1994) の枠組みで役割別サブ集団を進化させる
   MAD チーム最適化手法の提案
3. 4B 級モデルで「素の debate は悪化しうる」(2502.08788, 2605.00914) 条件下でも、
   チームレベル選択圧が debate を機能させるかの実証分析

## 3. 適応度関数の設計（理論的根拠付き）

### 3.1 採用する定義

世代 t の役割 r の候補 LoRA c について、代表チーム文脈
T(c) = {c} ∪ {代表_r' | r' ≠ r} における**厳密 Shapley 値**を適応度の中核とする:

```
φ_c = Σ_{S ⊆ T(c)\{c}} [|S|!(2-|S|)!/3!] · (v(S∪{c}) − v(S))
fitness(c) = φ_c · sharing_penalty(c)
```

- v(S): 連合 S が debate プロトコルで達成した適応度セット上の精度（v(∅)=0、
  v({i}) = solo 精度）。3エージェントなので全 7 連合の実測で**近似なしの厳密計算**。
- 根拠: Shapley 値は効率性・対称性・null player・線形性の公理を一意に満たす
  貢献配分 (Ghorbani & Zou 2019, 1904.02868; Rozemberczki+ IJCAI22)。
  LOO 近似の欠陥（複製に貢献0を与える等）を回避。φ_c は v({c}) を通じて
  個体性能を内包するため、性能項を別途加算しない。
- **多様性は適応度に加算しない**: QD 文献 (MAP-Elites 1504.04909) と
  アンサンブル統一理論 (Wood+ JMLR23, 2301.03962) の双方が加算を批判。
  代わりに fitness sharing (Goldberg & Richardson 1987) の乗法ペナルティ:

```
sharing_penalty(c) = 1 / (1 + Σ_{c'≠c, 同役割} max(0, 1 − d(c,c')/σ_share))
```

  d(c,c') は適応度セット上の**回答不一致率**（行動距離）。同一ニッチに
  密集した個体の適応度を割り引き、早期収束を防ぐ。

### 3.2 アブレーション（新規性の直接検証）

- **A1: fitness = solo 精度のみ**（GENOME 型）→ RQ1(a) の直接比較
- **A2: sharing なし**（φ のみ）→ 多様性維持の寄与を分離
- **A3: 交叉方式**: ΔW 空間ブレンド+SVD（主方式） vs A/B 別補間（従来 naive 方式）

## 4. 進化アルゴリズム

協調的共進化 (Potter & De Jong 1994) + PBT 型 exploit/explore (Jaderberg+ 2017):

- **集団**: 3 役割（批判的検証者/実務的意思決定者/発散的探索者）× 各 2 個体 = 6 LoRA
- **初期化 (gen 0)**: 役割別 SFT データ（各 60 例）で QLoRA 学習した 3 個体 +
  各役割の突然変異コピー 3 個体
- **世代ループ** (5〜8 世代):
  1. 各役割の代表（前世代最良）を固定し、各候補の 7 連合 debate 評価 → φ_c
  2. sharing 補正 → 役割内選抜（上位 1 が代表に）
  3. 次世代生成: 役割内/役割間の **ΔW 空間交叉**（B·A を計算して補間、
     SVD で rank r に再分解 — KnOTS 2410.19735 の交差項問題への対処）+
     ガウス突然変異
- **適応度セット**: MMLU-Pro テスト分割からの固定 100 問（最終評価分と非重複、
  tinyBenchmarks 2402.14992 の「100問で誤差~2%」根拠）。世代間の順位付け専用。

## 5. Debate プロトコル

文献ベストプラクティス (Debate or Vote 2508.17536; Voting or Consensus 2502.19130;
Demystifying MAD 2601.19921) に準拠:

- round 0: 独立回答（多様な初期解） → round 1〜2: 他者回答を見て批判的更新
  （ラウンド増は逆効果のため最大 2）
- 集約: **最終ラウンド回答の多数決**（judge エージェント不使用 — judge 能力が
  ボトルネックになる報告 2511.11040）
- 出力形式: 厳密な `ANSWER: <値>` 指定 + 正規表現抽出（confidence の言語化値は
  過信バイアスのため主集約に使わない）

## 6. 評価プロトコル

### 6.1 ベンチマーク（3 本柱、いずれもゲートなし）

| ベンチ | 規模 | 根拠 |
|---|---|---|
| MMLU-Pro (TIGER-Lab) | 固定ランダム 500 問 | base 69.6、MAD 改善報告と接続 |
| MATH-500 Level 4-5 | 全該当問題 (~200) × K=3 | 数学推論は MAD 改善が最大 |
| SuperGPQA (m-a-p) | 固定ランダム 300 問 | base 42.8、余地最大 |

GSM8K は Qwen3-4B で飽和（80-92%）のためスモークテスト専用。
GPQA-Diamond は HF ゲート付きのため不採用（HF トークン不要方針を維持）。

### 6.2 比較条件（全条件で同一問題・同一抽出ロジック・paired）

1. ベースモデル solo CoT（K=3 seed）
2. **Self-Consistency@9**（debate と計算量マッチ — Smit+ ICML24 対策で必須）
3. ベースモデル ×3 + 温度サンプリング debate（プロンプトペルソナのみ、Self-MoA 型対照）
4. gen-0 ペルソナ LoRA チーム debate
5. **進化後チーム debate（主要条件）**
6. 進化後 LoRA solo ×3（チーム効果と個体改善の分離）
7. A1: solo 適応度で進化したチーム debate（新規性の直接検証）

### 6.3 統計設計 (Miller 2411.00640 準拠)

- K=3 seed を問題内リサンプルとして扱い、問題単位の paired t 検定 +
  paired bootstrap (B=10,000) の 95%CI 併記。単一 seed 比較は McNemar。
- 3 ベンチ × 主要 2 比較に Holm-Bonferroni 補正。
- 検出可能効果量: 統合 N≈1,400 で +4〜5pt（Du+ の MAD 効果量 7〜15pt に対し十分）。
- 全実行に seed・モデル revision・vLLM バージョン・生成パラメータを記録。

### 6.4 副次評価

- 議論品質の LLM-as-judge（Vertex AI Gemini 2.5 Flash、pairwise + swap + tie 許容、
  rubric 4 項目、50-100 サンプル）。主要主張には使わない。
- 行動多様性の推移（回答不一致率・埋め込み距離）と ambiguity 分解の分析。
